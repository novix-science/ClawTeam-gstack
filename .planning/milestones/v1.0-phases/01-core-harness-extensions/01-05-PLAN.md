<objective>
Wire `HarnessOrchestrator` to the `PhaseRegistry` from Plan 01-01 and compose an optional `SprintState` from Plan 01-02 onto the orchestrator, completing the integration contract from RFC 001 §4.6. This is the Phase 1 "close the loop" plan: plugins can contribute phases (01-01), sprint state can persist (01-02), the interaction gate can scan (01-03), and question/answer files can be round-tripped (01-04) — but none of that reaches the harness until `HarnessOrchestrator.__init__` consults the registry. This plan adds that consultation while preserving every existing call-site's current behavior.

def __init__(
    self,
    team_name: str,
    goal: str = "",
    cli: str = "claude",
    agent_count: int = 3,
    phases: list[str] | None = None,
    phase_roles: dict[str, str] | None = None,
    human_gates: list[str] | None = None,

    self.team_name = team_name
    self.goal = goal
    self.cli = cli
    self.agent_count = agent_count

    self.state = PhaseState(
        team_name=team_name, goal=goal, cli=cli, agent_count=agent_count,
    )
    if phases:
        self.state.phases = phases
    if phase_roles:

    self.artifacts = ArtifactStore(
