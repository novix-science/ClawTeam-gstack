    ```python
    """Evidence-schema registry — plugin-populated frontmatter schemas keyed by artifact_type.

    Structural twin of clawteam.harness.phase_registry.PhaseRegistry (§02-CONTEXT lesson #3).
    Phase 3's GstackSprintPlugin.contribute_evidence_schemas() registers six concrete
    schemas (DesignDoc / PlanDoc / TestReport / ReviewReport / ShipNotes / Retro); Phase 2
    ships only the registry + the ArtifactFrontmatterBase.

    Consumers:
      - clawteam.plugins.manager._instantiate_and_register (Plan 02-01): calls
        register_schema for each entry returned by HarnessPlugin.contribute_evidence_schemas.
      - clawteam.harness.evidence_gate.EvidenceGate.check (Plan 02-07): calls
        get_schema(meta['artifact_type']) to dispatch per-artifact validation.

    Per §02-CONTEXT D-02 and D-03 + Pitfall #6: unregistered artifact_type returns None
    (distinguished from schema validation failure by the caller — Plan 02-07's gate emits
    "Unregistered artifact_type 'x'. Phase 3 plugin must register." on None).
    """

    from __future__ import annotations

    from pydantic import BaseModel


    class ArtifactFrontmatterBase(BaseModel):
        """Base pydantic model for durable-artifact YAML frontmatter.

        Field shape matches clawteam.team.envelope.TurnEnvelope (§02-CONTEXT lesson #2:
        one model, two surfaces). Phase 3 concrete subclasses add required section lists
        and artifact-specific fields (e.g., DesignDoc.forcing_questions, ShipNotes.deploy_url).

        All fields required — the gstack EvidenceGate (Plan 02-07) asserts these are
        populated before running the 4-check protocol; an agent that writes an artifact
        without these fields fails the gate with a structured error.
        """

        persona: str
        step_label: str
        done: bool
        artifact_type: str
        created_at: str


    # Module-level singleton dict; populated at plugin load time.
    _REGISTERED: dict[str, type[ArtifactFrontmatterBase]] = {}


    def register_schema(name: str, cls: type[ArtifactFrontmatterBase]) -> None:
        """Register a pydantic subclass of ArtifactFrontmatterBase under `name`.

        Raises ValueError on duplicate `name` (§02-CONTEXT D-03; mirrors PhaseRegistry).
        Collision message mentions both the name and the conflicting plugin so Phase 3's
        GstackSprintPlugin debug is trivial if it accidentally double-registers.
        """
        if name in _REGISTERED:
            raise ValueError(
                f"Duplicate evidence-schema registration: {name!r} "
                f"(existing: {_REGISTERED[name].__name__}, new: {cls.__name__})"
            )
        _REGISTERED[name] = cls


    def get_schema(artifact_type: str) -> type[ArtifactFrontmatterBase] | None:
        """Return the registered pydantic class for `artifact_type`, or None if unregistered.

        Caller MUST distinguish None (Phase 3 forgot to register) from model_validate()
        failure (schema present, data invalid) — Pitfall #6 in RESEARCH.
        """
        return _REGISTERED.get(artifact_type)


    def list_registered() -> list[str]:
        """Return the sorted list of registered artifact_type names (for diagnostics)."""
        return sorted(_REGISTERED.keys())


    def reset_registry() -> None:
        """Clear all registered schemas — TEST-ONLY helper for isolation.

        Tests MUST call this in setup_function / teardown_function (mirrors
        clawteam.harness.phase_registry.reset_registry convention).
        """
        _REGISTERED.clear()
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin code → `register_schema(name, cls)` | plugin supplies both the name and the class; name collisions could be accidental or malicious (later plugin shadows earlier); `cls` must subclass `ArtifactFrontmatterBase` (guarded at plugin load by pydantic when EvidenceGate later calls `model_validate`) |
| EvidenceGate → `get_schema(name)` | gate passes attacker-controlled `artifact_type` from parsed frontmatter; the `.get(...)` returns None for unknown names without raising — safe |
