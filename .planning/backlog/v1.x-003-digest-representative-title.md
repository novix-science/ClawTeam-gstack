# attend --summary "Representative title" column shows qid instead of actual title

## Repro

Drop questions with meaningful titles (first H1 in the markdown body) into a sprint. Run `clawteam attend --summary`. The "Representative title" column displays the question id (e.g., `q001`) instead of the human-readable title (e.g., "Should the badge use pyproject.toml or hardcode?").

## Why this matters

Digest mode exists to make 20+ pending questions scannable. If each row only shows qids, the user still has to run `attend` (non-summary) or `attend pick <qid>` on every one to know what each group is about — defeats the purpose of the digest.

## Expected

Parse the first `# Header` line from each question.md and surface that as the representative title (truncate to 60-80 chars).

## Files

- `clawteam/attention/digest.py::build_digest` — needs to extract titles from question bodies
- `clawteam/cli/commands.py` — attend_root `--summary` branch renderer
